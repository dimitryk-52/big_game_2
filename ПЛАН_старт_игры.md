# План: как начинается игра (ТВ без кнопок, всё с пульта)

Сценарий: **пустой фон → Интро (логотип + звук → песня) → Лобби-тропа с QR → «Начать» → 3-2-1 → карта + музыка калибровки → «Далее» → калибровка → обычная игра.**

## Что уже есть (проверено)
- Админка шлёт команды на ТВ: `ctl(cmd, args)` → `net.send('input', {t:'ctl'})` → `host.ctl()` ([admin/main.tsx:250](src/admin/main.tsx:250), [host/host.ts:86](src/host/host.ts:86)). Новые команды добавляются по той же схеме.
- Фазы игры: `'lobby' | 'calib' | 'landing' | 'turns' | 'end'` ([shared/types.ts:455](src/shared/types.ts:455)).
- Меню звуков: `SOUND_GROUPS` + музыка `musicId(...)` ([shared/sounds.ts](src/shared/sounds.ts)), вкладка в [admin/Sounds.tsx](src/admin/Sounds.tsx).
- Кнопки на ТВ, которые надо убрать: лобби ([tv/TvApp.tsx:402](src/tv/TvApp.tsx:402)) и панель внизу ([tv/TvApp.tsx:663](src/tv/TvApp.tsx:663)).
- Логотипы: `LOGO_URL`, `LOGO_TEXT_URL` ([shared/logo.ts](src/shared/logo.ts)).

## Решение: подэтап внутри лобби
Не плодим новые фазы движка. В состояние добавляем `show`:
- в фазе `lobby`: `show: 'blank' | 'intro' | 'walk' | 'countdown'`
- в фазе `calib`: флаг `calibWait: true`, пока ведущий не нажмёт «Далее»

Игроки могут заходить на любом подэтапе лобби, но появляются на экране только в `walk`.

---

## Этап 1. ТВ без кнопок + запуск без потери фокуса (маленький)
1. Убрать все кнопки и `confirm()` с ТВ. Горячие клавиши (пробел, P, F) оставить как запасной вариант.
2. Перенести на пульт: «Новая игра», звук вкл/выкл на ТВ, «Отладка: экран», «+ бот». «Далее/Пауза/Завершить» на пульте уже есть.
3. **Фокус и автозапуск звука.** Сам по себе потерянный фокус анимации не останавливает: браузер тормозит только скрытые или перекрытые окна. Главная угроза — запрет автозвука: ТВ без клика может не играть звук. Решение: «Запустить ТВ.bat» открывает ТВ отдельным Chrome/Edge с флагами:
   - `--autoplay-policy=no-user-gesture-required` (звук без клика)
   - `--disable-renderer-backgrounding --disable-background-timer-throttling --disable-backgrounding-occluded-windows`
   - `--kiosk` (или `--start-fullscreen`) + `--window-position=X,0` (на ТВ-монитор)
   - отдельный `--user-data-dir=%TEMP%\bg2-tv` — иначе флаги не применятся, если браузер уже открыт
4. Проверка: ТВ в киоске на втором мониторе, кликаем по пульту на первом, анимация и звук идут.

## Этап 2. Логика старта + звуки (средний)
1. Команды пульта: `intro` (blank→intro), `next` в лобби (intro→walk), `start` (walk→countdown→calib с `calibWait`), `next` при `calibWait` → начинается калибровка. Подписи кнопки на пульте через `nextLabel(s)`.
2. Новая группа звуков **«Начало игры»** в меню:
   - `introSting`: звук вылета логотипа
   - `music:intro`: песня после интро (если в лобби-тропе нужна другая, добавить `music:lobby`)
   - `count3`, `count2`, `count1` (+ по желанию `countGo`): озвучка цифр
   - `toMap`: звук перехода на карту
   - `music:calib`: играет всю калибровку, потом включается обычная `music:map`
3. ТВ: экран `blank` (просто фон); `intro` (логотип вылетает одновременно с `introSting`, по окончании звука включается песня); `countdown` (музыка затихает, крупно 3-2-1 со звуками, затем эффект перехода: белая вспышка/зум/шторка → карта); `calibWait` (карта + `music:calib`, плашка «Калибровка»).

## Этап 3. Лобби-тропа с параллаксом (большой, в основном арт)
1. Раскладка: сверху текстовый логотип + QR, снизу тропа с игроками.
2. Слои фона (рисуем через pxl, в японском стиле), от дальнего к ближнему:
   1. небо + Фудзи: очень медленно, **без цикла** (картинка шире экрана, едет за всю сессию)
   2. дальние горы/лес: медленно, цикл
   3. средний план (пагода, тории, сакура, домики): цикл
   4. ближний план (кусты, фонари, камни): цикл
   5. сама тропа/трава: быстрее всех, цикл
   Скорости, например, 0.02 / 0.1 / 0.3 / 0.6 / 1.0. Циклящиеся слои должны бесшовно стыковаться по краям.
3. Персонажи: модульные спрайты игроков (characters v2, смотрят вправо) с анимацией ходьбы на месте. Новый игрок входит слева и доходит до своего места. Места распределены по тропе, со смещением по глубине, чтобы толпа не сливалась.
4. Производительность: одна канва или CSS `transform`/`background-position` на слой + `requestAnimationFrame`, пиксельная чёткость (`image-rendering: pixelated`, целые смещения).

---

## Порядок и объём
- Этап 1: короткий, одна сессия.
- Этап 2: одна сессия. Звуковые файлы пользователь подставит потом через меню звуков (пока будут пустые слоты/синт).
- Этап 3: отдельная сессия. Сначала арт слоёв (pxl), потом сцена.
- Файлы музыки/озвучки ищет пользователь, код от них не зависит.
