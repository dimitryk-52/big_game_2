# Картинки джа-одори (танец дракона, Нагасаки)

Игра ищет здесь PNG. Нет файла — рисуется запасной пиксельный вариант из кода (`src/games/dragonArt.ts`),
так что класть файлы можно по одному. После `npm run dev` страница подхватит новый файл сама.

| Файл | Что это | Пропорции → ширина, px | Фон |
|---|---|---|---|
| `street.png` | Улица Нагасаки ночью (фестиваль Кунчи, фонари). Вид строго сбоку. Нижняя десятая часть — пустая мостовая, по ней идут игроки. Повторяется по горизонтали, края должны сходиться | 21:9 → 420 (≈420×180) | непрозрачный |
| `head.png` | Голова дракона, смотрит **вправо**, шея ровно срезана слева | 1:1 → 48 | прозрачный |
| `body.png` | Прямой кусок туловища, оба конца ровно срезаны (кусок повторяется вдоль всей волны) | 4:3 → 32 | прозрачный |
| `tail.png` | Хвост: справа ровный срез, хвостовой плавник уходит **влево** | 4:3 → 40 | прозрачный |
| `pearl.png` | Жемчужина, за которой гонится дракон | 1:1 → 16 | прозрачный |
| `sky.png` | *По желанию.* Дальний план (небо, холмы, бухта). Едет медленнее улицы. Если он есть, у `street.png` небо над крышами должно быть прозрачным | 21:9 → 420 | непрозрачный |

Размер в пикселях не важен: игра подгоняет картинки по высоте (голова, туловище и хвост — в одном
масштабе между собой, так что рисуй их одного дракона). Важно направление: голова смотрит вправо.
Ноги игроков стоят на 90% высоты `street.png` (константа `STREET_GROUND` в `src/games/dragonArt.ts`).

## Как нарисовать в Nano Banana

1. В `.env` нужен `GEMINI_API_KEY`. Запусти «Пиксель-арт.bat» (или `npm run pixelart`), открой http://localhost:4180.
2. На закладке «Очередь» нажми «Взять» у нужной картинки джа-одори: промпт, пропорции, ширина, фон и референсы выставятся сами.
3. Для улицы приложи референсом `src/img/bgs/bg_nagasaki.png`, чтобы стиль совпал с фоном префектуры.
4. Начни с головы. Удачный вариант → «Как референс», потом туловище и хвост: так они получатся одного дракона.
5. На карточке результата проверь «пиксели» (ширину и «Убрать фон» можно подкрутить) и нажми **«В игру»**:
   картинка в 1× ляжет сюда под нужным именем.

Модель плохо делает бесшовные края. Если стык улицы заметен, поправь края в любом пиксельном редакторе
(Aseprite, Piskel) или сдвинь картинку на полширины и дорисуй середину.

Игроки — те же человечки, что на карте (`src/shared/sprites.ts`). Нарисуешь новых, и в танце они появятся сами.
